# 中文 AI 腔模式全表

分三级：**强**（见一次就改）、**中**（同一段出现两个以上再改）、**弱**（全文扎堆才改）。每条都给"改"和"留"：清单管的是修辞动作，不是字面。命中词表但在句子里有实际意思的，留着；没在表里但在做同样动作的（换个说法继续抬高、继续铺垫），照样改。

## 一、强信号

### 1. 假对比
不是 X，而是 Y / 不仅仅是 X，更是 Y / 与其说 X，不如说 Y / 你以为 X，其实 Y / 真正的 X 从来不是……
- 改：这不仅是一个导出按钮，更是通往高效工作的入口。→ 这个按钮可以导出 CSV。
- 留：错误发生在保存阶段，而不是上传阶段。（两半都有信息）
- 按作用判断。真实纠错、实际取舍和条件边界可以直接说。空对比倒装以后仍然是空对比。

### 防御性叙述
先给自己免责、回应没人提出的异议，或把明确的事实包在多重限定语里。直接交代依据支持的事实、判断或行动。凡是影响读者决定的风险、范围和禁止，保留原来的力度。
- 改："这并不意味着我们已经解决了所有问题，但可以说，目前在一定程度上缩短了校验时间。" → "试运行期间，单次备份校验平均用时从 12 分钟降到 8 分钟。"（原始材料有该范围和数据时）
- 留："试运行只用了小文件，大文件的校验时间尚未测量。"（这个边界影响结果的适用范围）

### 2. 单句收尾、段尾解说、碎句造势
段尾一句"这就是坚持的意义。" / "答案，就在其中。" / "三年。两个人。一个想法。"
段尾解说：事实或例子讲完，再补一句它说明了什么："这说明方案可行，但还不够快。" / "这正是本项目要解决的问题。" / "这也是我们坚持做这件事的原因。"
- 改：删掉读者已知的意义或复述。因果本身能改变理解时，跟着相关事实交代，句号放在读者好读的地方。
- 改：两个人花了三年，把这个想法做成了产品。
- 留：我不同意。现在的数据还不够。（短句承载新信息）

### 3. 伪格言、伪洞见
X 是 Y 的语言 / 本质上 / 归根结底 / 底层逻辑是 / 最后比拼的是 / 核心在于 / 说到底
- 改：协作是效率的语言。→ 两个人一起核对同一份清单，返工少了一半。（只用原文已有的事实）

### 4. 起跑式铺垫
让我们一起来看看 / 接下来我将为你 / 下面我们深入探讨 / 话不多说 / 先说结论（后面紧跟的就是结论）/ 一句话总结
- 改：删掉，直接说。
- 留：说实话，我还没想好。（真情绪，不是铺垫）

### 5. 时代背景开头
在当今社会 / 随着……的不断发展 / 在这个……的时代 / 在……的大背景下
- 留：随着文件数量增加，检索时间也在变长。（真实的因果）

### 6. 意义拔高
标志着……的新时代 / 具有深远意义 / 迈出了坚实一步 / 为……奠定了坚实基础 / 彰显了……的不懈追求 / 注入新动能 / 开启新篇章 / 书写新篇章
- 改：团队周三开放了文件导出，标志着协作新时代的到来。→ 团队周三开放了文件导出。
- 留：这是团队第一次公开发布这个工具。（可核查的事实）

### 7. 套话收尾
综上所述 / 总而言之 / 总的来说 / 让我们拭目以待 / 未来可期 / 只有……才能…… / 让我们携手…… / 共创美好未来 / 与君共勉
- 留：综上，两种方案都满足不了离线要求，暂不采用。（真结论）

### 8. 聊天残留、谄媚
好问题！/ 你说得太对了 / 当然可以！/ 希望这对你有帮助 / 如果你还有其他问题 / 以下是为你整理的 / 需要我帮你……吗
- 留：邮件、书信、客服回复里的问候、感谢和落款。

### 9. 无源权威
研究表明 / 数据显示 / 有专家指出 / 业内人士认为 / 众所周知
- 有具体来源就写出来；写作时没有就不用。改写时不要删掉归属让它变成裸事实，在正文后提示"缺来源"。

### 10. 格式装饰
每条列表都是"**加粗标签**：内容" / 标题和列表里的 emoji / 三句话的内容拆成小标题 / 简单回复也 1. 2. 3.
- 改：**用户体验**：界面全面升级。**性能优化**：算法显著提升。→ 界面重做了，搜索快了一倍。（只用原文已有信息）

### 11. 商业黑话
赋能 → 帮、让……能；助力 → 帮；打造 → 做、建；抓手 → 办法；闭环（非技术用法）→ 说清做完了什么；颗粒度 → 细节；对齐 / 拉齐 → 统一、说好；沉淀 → 积累、记下来；痛点 → 问题；底层逻辑 → 原因；心智 → 印象；链路 → 流程；触达 → 联系到；赛道 → 领域；降本增效 → 省钱、提速。
- 留：闭环控制、协同编辑、用户洞察（功能名）等正式术语。

### 12. 调试腔、工程师腔（用在日常话题里）
兜住 / 兜底 / 收口 / 收敛 / 落盘 / 落地 / 根因坐实 / 打掉问题 / 对上了 / 更稳 / 接住 / 拆开看 / 口径 / 这轮
- 留：技术语境里有具体对象的，比如"请求峰值由限流兜底"。

### 13. 小红书腔、硬凹网感
姐妹们 / 绝绝子 / 谁懂啊 / 真的会谢 / 狠狠 xx 了 / 保姆级 / 干货满满 / 建议收藏 / 一文读懂 / 划重点 / 宝藏
- 真人偶尔用，AI 是批量用。除非用户就是要这个腔调，否则不用。

### 14. 咨询式安抚、替人下心理结论
我就在这里 / 稳稳地接住你 / 你不是敏感，你只是…… / 你已经做得很好了 / 我完全理解你的感受 / 这份脆弱
- 改：直接回应对方说的事。

### 15. 主动出击腔
要不要我帮你…… / 如果你愿意，我可以马上…… / 你一回复我就……
- 改写时：保留真实的交付动作、条件和主体，只删推销语气。

## 二、中信号（同段两个以上再改）

### 16. 抒情词给抽象概念穿衣服
安放 / 抵达 / 微光 / 褶皱 / 丰盈 / 滚烫 / 治愈 / 温柔地 / 时光 / 岁月 / 星辰大海 / 奔赴
- 改："把那些说不出口的情绪安放在时光的褶皱里" → 说清楚是什么情绪、做了什么。
- 留：写具体事物（把药盒安放在床头）；文学作品、用户要的抒情体。

### 17. 机械递进
首先……其次……再次……最后…… / 一方面……另一方面…… / 第一，第二，第三（内容其实不分先后）
- 留：真有顺序的操作步骤。

### 18. 四字词堆叠
稳定可靠、高效便捷、简单易用 / 精益求精、追求卓越 / 砥砺前行、勇毅前行
- 改：这套方案运行稳定、响应快，也好维护。（只保留有依据的）
- 留：中文本来的四字节奏；"数量不变、顺序不变、权限不变"这种三项各有内容的。

### 19. 程度副词扎堆
显著提升 / 有效解决 / 全面推进 / 持续优化 / 进一步加强 / 充分发挥 / 切实保障 / 深度融合 / 极致体验
- 有数字就用数字，没有就删掉副词。

### 20. 设问自答
那么，问题来了：…… / 为什么会这样？原因很简单：…… / 这意味着什么？
- 偶尔一次可以，每段都来一次就是腔。

### 21. 万能连接词
值得注意的是 / 值得一提的是 / 需要指出的是 / 不难发现 / 不可否认 / 事实上 / 实际上 / 与此同时 / 此外 / 然而 / 由此可见 / 换句话说
- 后面接的是真转折、真补充，留。只是开头垫一下，删。

## 三、弱信号（全文扎堆才改）

### 22. 翻译腔
- 进行 + 动词：对系统进行全面测试 → 全面测试系统（"正在""计划"等时态词保留）。
- 对于……来说 / 对于……而言：看能不能直接删。
- 作为一个……：作为一名产品经理，我认为 → 我是产品经理，我觉得……（或直接删）。
- 基于…… / 通过……来……：看能不能直接说动作。
- 一个……的……的……：长定语拆开。
- 被字句堆叠：被优化、被改进、被赋予 → 换主动句；施事者未知时保留。
- 在……方面 / 在……的过程中：多数可删。
- 它 / 他们 过多：中文常常省主语，英文式的每句都带代词读起来像翻译。

### 23. 破折号
中文破折号承担解释、插入、转折时正常。一段里两个以上，或用来制造悬念（"答案——出乎意料"），才改。

### 24. 限定词堆叠
也许可能会 / 在一定程度上或许 → 只留一个，保留真实的不确定。

### 25. 高频大词
重要、关键、核心、创新、优化、提升、推动、确保、实现、促进
- 单个都正常，全文每段都有，才说明在凑。

## 四、中英混排与排版

- 中文和英文、数字之间加空格：用 Claude 写了 3 篇文章（团队规范不加空格的，按规范）。
- 中文正文用全角标点，引号用“”或「」，不要用英文直引号。
- 英文专有名词、产品名保持原样大小写，不要翻译成奇怪的中文（GitHub 不写成"吉特哈布"）。
- 能用中文说清楚的不夹英文：不写"这个 feature 的 impact 很大"，除非是在模仿特定圈子的说话习惯。
